Design tip:

The tree view tab shows how each iteration is based on previous ones. The list view shows them in the order they were created. Both can be handy.

In the tree view, the arrow for each iteration points toward the one it's based on: that's either ⇖ for the one to the left and above or ⇑ for directly above. Click the dropdown buttons to collapse sections of the tree.

In either view, you can use the up and down arrow keys to scroll through the design iterations while viewing each in the Preview window. Navigate up and down through the views with arrow keys.
