Design tip:

The tree view tab shows how each iteration is based on a previous one. The list view shows them in order of creation. Both are handy.

For each iteration in the tree view, an arrow points toward the one it's based on: ⇖ for the one to the left and above or ⇑ for directly above. Click dropdown buttons to collapse sections of the tree.

Use up and down arrow keys to scroll through iterations. The Preview window shows each one.
